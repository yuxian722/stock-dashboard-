SECS格式化參數（S7F25FormattedPPRequest）

機台目前的製程參數(Equipment Constants/Recipe參數)基準清單，之後可以跟Excel目標清單比對哪些已經有、哪些還沒加進去

Log裡的S7F25FormattedPPRequest（Type="Reply"）事件會記錄一次完整的參數快照： PP_ID/MDLN/SOFTREV（這是哪一組recipe／機型／軟體版本）加上 一長串<Item>，每個Item是一項參數（CCODE編號＋名稱／單位／格式／ 數值／下限／上限）。下面①是2026/08/19從真實log解析出來、固定內建在這頁裡的199組基準參數 （RECIPE@AEU132X2C001A-2070），不用每次都重新上傳log才看得到。

1目前機台基準參數清單（共 0 組）

2跟Excel目標清單比對（Check List）

2026/08/20用你提供的真實Excel確認格式：第一列欄位標題要是Item / Name / ID number / ID name（跟你這份檔案一樣），以「ID number」欄位(就是CCODE)當比對的鍵——因為參數名稱本身 在真實資料裡會重複(例如好幾個不同辨識設定底下都各自有一個「Rec. threshold matching rate」)， CCODE才是每一項參數唯一的編號。上傳後會分成三類：①兩邊都有(機台已經有、Excel清單也有) ②機台有、Excel清單沒有 ③Excel清單有、機台還沒有(你要慢慢加進去的目標)。

③ Excel清單有、機台還沒有（要新增的，共 0 組）

② 機台有、Excel清單沒有（共 0 組）

① 兩邊都有（共 0 組，0 組名稱有出入）

3（進階/選用）從其他SECS Log重新解析

如果想確認另一份log自己記錄到的參數快照(不是上面固定的基準清單)，可以在這裡上傳、單獨解析查看。

4該份log的參數快照（共 0 筆）

「全部匯出」是這份log的所有快照一次匯出成一個檔案(Excel是每個快照各自一個工作表)；下面每個快照 自己也有「下載CSV」，只匯出那一筆快照。
